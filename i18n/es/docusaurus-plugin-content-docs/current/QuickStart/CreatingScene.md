# 3) Creating a Scene

Click to composition tab and choose a scene type to create your first scene. 

**Trackless** scenes are used for animating and moving the camera inside Qimera. **Tracked** scenes are used for creating a scene with camera tracking information.

![Qimera Launcher](/img/QuickStart/FirstScene.png)

You can manage your scenes and virtual camera selection from this menu.

![Qimera Launcher](/img/QuickStart/SceneMenu.png)

Congratulations! You have created your first scene in Qimera. You can now start reading the rest of the documentation to learn more about Qimera's features and capabilities.
