1\. When opening the "Components editor" we can see that Qimera separates the asset into sections such as:

1. ***"Texts"***
2. ***"Meshes"***
3. ***"Scene components"***

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-07-29/99accf1a-1dad-410c-8469-abddaa27e61b/user_cropped_screenshot.webp?tl_px=280,163&br_px=1656,932&force_format=jpeg&q=100&width=1120.0)


2\. We display some of the texts and change the data. (In this case ***"info 1"***)

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-07-29/5542ed24-cffd-4e03-9edc-0fe259607436/user_cropped_screenshot.webp?tl_px=280,163&br_px=1656,932&force_format=jpeg&q=100&width=1120.0)


3\. If we do not see the changes in real time (viewport) we have to switch on the ***"Live update"*** and finally click on the ***"Load page"*** to load those new values.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-07-29/d72ca6bd-e36a-45d7-826d-6e0f2c85b270/user_cropped_screenshot.webp?tl_px=280,163&br_px=1656,932&force_format=jpeg&q=100&width=1120.0)


4\. We can now see the change we made (***"Carrera"*** to ***"RACE"***)

If we don't see all the components, there is a bar that we can access.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-07-29/87e82e72-65a3-4738-81ff-43d342f5d882/user_cropped_screenshot.webp?tl_px=560,326&br_px=1936,1096&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=716,541)


5\. In this case, if we want to change the player's image, we click on it.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-07-29/89b7a174-4cfd-4660-9c46-87bafccfd0c7/ascreenshot.jpeg?tl_px=0,0&br_px=1376,769&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=419,82)


6\. It will highlight the component name to speed things up, and there we'll display the options.

We'll find the ***"Material slot"*** where that texture is stored. ***(Material 0)***

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-07-29/91b46096-43d0-4ba0-859c-f4046d039050/user_cropped_screenshot.webp?tl_px=250,326&br_px=1626,1096&force_format=jpeg&q=100&width=1120.0)


7\. Once we select the corresponding material slot, we can access the texture.

There are two ways to change our images/textures.

1. Searching in the ***"Content Browser"***

2. ***"Typing the file name"***


8\. 1\. Click on ***"Content Browser"*** to search the image bank that we have saved in our project.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-07-29/eb2cfe7f-dc2f-47fb-9bee-31083efa5a57/ascreenshot.jpeg?tl_px=560,326&br_px=1936,1096&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=526,436)


9\. Press [[F11 ]]to go to the Unreal editor and select the image. (The image will be inside the folder where we imported it).

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-07-30/4a7d3edc-870c-45bb-b7d7-1b44e1e59f6c/user_cropped_screenshot.webp?tl_px=0,326&br_px=1376,1096&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=290,362)


10\. Click assign (arrow) to place the texture.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-07-30/3f66fb10-82f0-49bc-8437-11e7fad7c01d/user_cropped_screenshot.webp?tl_px=0,0&br_px=1920,1080&force_format=jpeg&q=100&width=1120.0)


11\. 2. ***"Typing the file name"*** inside the ***"Search Assets"*** box.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-07-29/a8f0092e-c5dd-46bd-baef-32494d744356/user_cropped_screenshot.webp?tl_px=560,193&br_px=1936,962&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=577,277)


12\. We put the name of the image file that is saved in our project and select it (in this case ***"Messi"***).

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-07-29/50f863ed-0f7e-4e2c-9f84-b941d8b82b96/user_cropped_screenshot.webp?tl_px=280,163&br_px=1656,932&force_format=jpeg&q=100&width=1120.0)


13\. We deploy the ***"Position"*** module and adjust the location (in this case the X axis).

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-07-29/e67e26e7-131f-4cce-b954-92a11efd7871/user_cropped_screenshot.webp?tl_px=426,326&br_px=1802,1096&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=524,432)


14\. We can add pages within an asset to generate different instances.\
Click on ***"Add Page".***

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-07-29/f4c105dc-e579-4970-a7c6-f079304a6886/ascreenshot.jpeg?tl_px=423,0&br_px=1800,769&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=524,111)


15\. We select our new page ***"Page 1"*** and load it in ***"Load Page"***.

Now you can edit the page exactly as we did in [[Step 5]].

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-07-29/74284b12-b8d6-4b4b-8615-33ee5a586386/user_cropped_screenshot.webp?tl_px=280,163&br_px=1656,932&force_format=jpeg&q=100&width=1120.0)


16\. Just like text and images, we can also change the color of our meshes.

1. Click on the mesh you want to modify.
2. Open the ***"Material Options"*** panel.
3. Choose the corresponding material slot.
4. Click on the ***"Value"*** color field.
5. Find the desired color in the ***"Color Picker"***.
6. Click "***OK"*** to accept the changes.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-07-30/ba171ecc-f9d8-43a5-9c67-6a715fd6bf21/user_cropped_screenshot.webp?tl_px=0,0&br_px=1920,1077&force_format=jpeg&q=100&width=1120.0)


17\. We can activate/deactivate different types of transitions for these pages by displaying the ***"Transitions"*** module.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-07-29/6393e348-ab2d-4bf2-90a8-b51d932e0d5b/user_cropped_screenshot.webp?tl_px=560,0&br_px=1936,769&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=602,191)


18\. To return to the previous page, simply click on the desired page again and Click on ***"Load Page"***
