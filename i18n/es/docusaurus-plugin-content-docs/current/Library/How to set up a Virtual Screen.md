title: How to set up a Virtual Screen
sidebar_position: 3
---
1\. Once we've selected the mesh where the video will be played, we need to find the appropriate texture within the corresponding ***"Material slot"***.

1. Click on the mesh (***"ScreenC"*** in this case).

2. Click on ***"None"*** to open the list of materials and search for the appropriate material (in this case ***"Material 0"***).

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-08-05/27cd115c-3b84-4fd6-bf59-517f938560b3/user_cropped_screenshot.webp?tl_px=352,175&br_px=1728,944&force_format=jpeg&q=100&width=1120.0)


2\. We need to activate the ***"As virtual screen"*** box to access some advanced settings.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-07-30/acfd5fb1-d5b4-465c-a2c7-9eeca6b2fda2/ascreenshot.jpeg?tl_px=544,310&br_px=1920,1080&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=712,257)


3\. We can assign different types of sources:

1. [[Still Image]]
2. [[Internal]]
3. [[External]]
4. [[Image Sequences]]


4\. [[STILL IMAGE]]

1. Scroll down the menu until you find the ***"Screen Parameters Editor"*** module and choose ***"Still Image"*** in the source.
2. [[Click on ]]***"None"*** in the ***"Texture Input"*** search bar.
3. When the menu of all the textures in the project appears, [[select]] the desired one.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-08-05/add94282-527e-4018-9eea-f7cdde148089/user_cropped_screenshot.webp?tl_px=544,310&br_px=1920,1080&force_format=jpeg&q=100&width=1120.0)


5\. Once you have chosen the texture, [[click on]] ***"Load Page"*** to load the texture (make sure "***Live Update"*** is [[turned on]] to see the changes in real time).

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-08-05/4acd999f-7837-46e4-9596-85baa483a686/user_cropped_screenshot.webp?tl_px=352,149&br_px=1728,919&force_format=jpeg&q=100&width=1120.0)


6\. We can access several parameters to fine-tune our image.

1. ***Tiling***

2. ***Move***

3. ***Color Luminance***

4. ***Material Modes***

   If we change the ***"Shading Model"*** from ***"Unlit"*** to ***"Lit",*** our screen will not be affected by the lights in the virtual space.

5. ***Mesh Options***

   We can also activate ***"Sharp"*** to achieve better video quality.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-08-05/72959d0d-8847-47c6-b2ef-cb4351beee4d/user_cropped_screenshot.webp?tl_px=270,235&br_px=1780,1080&force_format=jpeg&q=100&width=1120.0)


Tip: We can add different pages to assign different ***source*** types.


7\. [[INTERNAL]]

1. Click on ***"Add Page".***
2. Click on the new page we just created (***"Page 1"*** in this case) and click on ***"Load page"*** to load it.
3. We chose the ***"Internal"*** source.
4. To assign the texture we made previously, click on ***"None"*** in the ***"Media Texture"*** search bar.

[How to create a media texture](https://scribehow.com/viewer/How_to_create_a_Media_texture__83AuHBo4TmSSlA3nOkifDw?referrer=documents)

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-08-06/b6f6a8ae-e723-4a77-89f6-9c31c542439b/user_cropped_screenshot.webp?tl_px=544,53&br_px=1920,822&force_format=jpeg&q=100&width=1120.0)


8\. We choose the desired texture (we can search in the bar by name to filter between textures).

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-08-06/059b7f92-e9c0-45b3-9a05-3e31c0654a31/user_cropped_screenshot.webp?tl_px=544,17&br_px=1920,786&force_format=jpeg&q=100&width=1120.0)


9\. Virtual screens have different types of transitions to change pages.

1. Click on "***Transitions"*** to display the menu.
2. We chose ***"Screen Fade"*** which fits better in this type of cases.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-08-06/5406e661-f159-4cc6-8cd3-7bdb730ee1b0/user_cropped_screenshot.webp?tl_px=196,0&br_px=1572,769&force_format=jpeg&q=100&width=1120.0)
