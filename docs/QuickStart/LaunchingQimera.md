# 4) Launching Qimera

Choose a map to launch Qimera. You can select a map from the list or use the search bar to find a specific map.

![Qimera Launcher](/img/QuickStart/QimeraLauncherMaps.png)

Choose the composition type you want to run this server with.

![Qimera Launcher](/img/QuickStart/QimeraLauncherCompositionType.png)

You can use the Qimera Launcher button to launch Qimera with the selected map and composition type.

| <img src="/img/QuickStart/LauncherButton1.png"    alt="Map selection"       style={{verticalAlign:'top', width:'100%'}} /> | <img src="/img/QuickStart/LauncherButton2.png" alt="Composition type" style={{verticalAlign:'top', width:'100%'}} /> |
| --- | --- |

You should see Qimera Interface running with the selected map and composition type.

![Qimera Launcher](/img/QuickStart/QimeraInterface.png)
