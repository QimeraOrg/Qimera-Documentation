title: Creating a Scene
---

1. Open **Composition** tab.
2. On top right go to the **Scene Selection**.
3. Use the plus sign to create the new scene.
4. Give it a descriptive name (e.g., `StudioA_Wide`, `XR_Garden_CloseCam`).
5. Select the created scene to start editing the settings for that scene.
